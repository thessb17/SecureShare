# SecureShare screenshot guide

Do not commit screenshots containing real passwords, tokens, private keys, personal data, local filesystem paths, or other secrets. Use fictional demo accounts and sanitized data.

Recommended portfolio captures:

1. `01-login.png` — login/register screen
2. `02-dashboard.png` — authenticated dashboard
3. `03-upload.png` — encrypted file upload result
4. `04-file-list.png` — encrypted file listing
5. `05-share.png` — share creation/permissions
6. `06-public-link.png` — protected public-link flow
7. `07-audit.png` — audit trail
8. `08-admin.png` — admin/RBAC view
9. `09-api-docs.png` — Swagger/OpenAPI screen
10. `10-architecture.png` — architecture diagram if desired

Only add screenshots after reproducing the corresponding flow successfully. The names above are a guide; missing screenshots are preferable to misleading ones.
